# Anand Binu Arjun - Cybersecurity Specialist & Developer Portfolio

Welcome to my professional portfolio website showcasing my expertise in cybersecurity and web development. This responsive website features multiple themes, interactive elements, and a comprehensive showcase of my projects and skills.

## 🌐 Live Demo
[[DEMO ](https://portfolionew-xi-three.vercel.app/)]

## 🎯 Features

### Theme Switching
- **Light Theme**: Clean, professional appearance
- **Dark Theme**: Eye-friendly dark mode for extended viewing
- **Neon Theme**: Modern cyber-inspired aesthetic with glowing effects
- Theme preference saved in localStorage for returning visitors

### Responsive Design
- Fully responsive layout that works on mobile, tablet, and desktop
- Built with Bootstrap 5 for consistent cross-device experience
- Optimized for all screen sizes

### Interactive Elements
- Smooth scroll animations triggered on element visibility
- Project filtering capabilities
- Form validation with user feedback
- Button ripple effects for enhanced UX
- Parallax mouse movement effects in hero section

### Project Showcase
- Comprehensive display of GitHub projects
- Toggle between projects and tools/technologies
- Project tags for easy categorization
- Direct links to GitHub repositories

## 🛠️ Technologies Used

### Frontend
- **HTML5**: Semantic markup for accessibility
- **CSS3**: Custom styling with CSS variables for theming
- **JavaScript**: Interactive functionality and DOM manipulation
- **Bootstrap 5**: Responsive grid system and components

### Tools & Libraries
- **Font Awesome**: Iconography
- **Google Fonts**: Typography

## 🚀 Getting Started

### Prerequisites
- Any modern web browser
- Python (for local server, optional)

### Installation
1. Clone the repository:
```bash
git clone https://github.com/AnandBinuArjun/portfolio.git
```

2. Navigate to the project directory:
```bash
cd portfolio
```

3. Start a local server (optional):
```bash
python -m http.server 8000
```

4. Open your browser and visit `http://localhost:8000`

## 🎨 Theme Customization

- **Dark Theme**: Modern dark interface
